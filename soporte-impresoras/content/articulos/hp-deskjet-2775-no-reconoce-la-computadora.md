# HP DeskJet 2775 no reconoce la computadora: qué revisar

> Este sitio es independiente y no es soporte oficial de HP.



## Respuesta rápida

La DeskJet 2775 se configura con la **app HP** (Microsoft Store en Windows), no solo con el cable. Si ya conectaste el USB, desconéctalo y empieza de nuevo.

## Qué revisar

1. **Elimina la impresora y reinicia.** Si ya la habías conectado, desconecta el USB. Abre **Impresoras y escáneres**, selecciona la impresora, **Quitar dispositivo** y reinicia la computadora.
2. **Usa un puerto USB directo.** No uses hubs ni bases de acoplamiento: la impresora puede no recibir suficiente energía.
3. **Instala la app HP** desde la Microsoft Store, ábrela y sigue la instalación guiada. Si no empieza sola, toca el signo **+** para añadir la impresora.
4. **Revisa el Administrador de dispositivos** con el USB conectado. Si la impresora aparece ahí, Windows detecta el cable. Si no aparece de ningún modo, puede ser el cable, el puerto o el equipo.
